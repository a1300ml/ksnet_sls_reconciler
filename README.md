# 런케이에듀 SLS 매출 조회

SLS의 `학원별 수납집계` Excel 파일에서 런케이에듀 귀속 매출만 월별로 조회합니다.

## 실행

1. 최초 1회 `install.bat`을 실행합니다.
2. `run.bat`을 실행합니다.
3. **SLS 파일 첨부**에서 월별 집계 파일(`.xlsx` 또는 `.xlsm`)을 선택합니다.
4. 조회 월과 매출 구분을 선택합니다.
5. 필요하면 **현재 조회 엑셀 저장**으로 결과를 저장합니다.

## KSNET·KCP 부가세 참고자료 조회

메인 화면의 **부가세 참고자료 조회**를 누르면 다음 세무 구분별로 PDF·Excel 파일을
여러 개씩 한 번에 첨부할 수 있습니다.

- 현금매출
- 판매(결제)대행매출
- 신용카드매출

첨부 후 **첨부자료 집계 실행**을 누르면 4월·5월·6월과 같은 월별 금액 및 전체 통합
금액이 표시됩니다. 집계 결과는 월별 집계 시트와 첨부파일별 금액 시트가 포함된
Excel 파일로 저장할 수 있습니다.

집계 후 **홈택스와 비교**를 누르면 매월 현금매출·판매(결제)대행매출·신용카드매출별
`별도 첨부자료 / 홈택스 / 차이`와 월 합계 및 전체 통합 차이를 확인할 수 있습니다.
홈택스 금액은 별도 첨부자료에 더하지 않고 비교 대상으로만 사용합니다.
비교표 마지막에는 현금매출 전체, 판매(결제)대행매출 전체, 신용카드매출 전체 및
모든 매출의 전체 통합 행이 표시됩니다.
현금매출의 홈택스 비교값은 `현금매출 파일 첨부`에 선택한 홈택스 현금영수증 금액을
동일하게 사용하므로, 정상적으로 같은 파일을 비교하면 현금매출 차이는 0원입니다.
비교 창의 **엑셀 저장** 버튼으로 화면과 동일한 월별·매출구분별 비교, 월 합계,
매출구분별 전체 합계 및 전체 통합 내역을 Excel로 저장할 수 있습니다.

## SLS 비율 배분 매출

SLS 파일과 부가세 참고자료 집계가 준비되면 메인 화면의 **SLS 비율 배분 매출 조회**를
누릅니다. 프로그램은 각 `조회 월 × 매출 구분`에서 SLS의 관별·항목별 금액 비율을
계산하고, 참고자료 집계금액을 같은 비율로 배분합니다. 원 단위 반올림 잔액도 조정하여
배분합계가 참고자료 원금액과 정확히 일치합니다.

조회 화면에서는 조회 월과 현금매출·판매(결제)대행매출·신용카드매출·전체를 선택할 수
있습니다. **세무사 제출용 4개 엑셀 저장**을 누르면 지정한 폴더에 다음 파일이 함께
생성됩니다.

- 현금매출
- 판매(결제)대행매출
- 신용카드매출
- 합산액매출

각 파일에는 `종합` 및 월별 시트가 포함됩니다. 합산액매출 파일은 수강료와 교재매출을
면세, 가맹점유저와 가맹점매출을 과세로 구분하여 면세금액·과세금액·총 매출액을
별도로 표시합니다.

## 홈택스 비율 배분 매출

메인 화면의 **홈택스 비율 배분 매출 조회**는 신용카드와 판매(결제)대행매출에
홈택스 자동분류 자료의 월별 금액을 사용합니다. 현금매출은 홈택스 자동분류 자료가
아니라 `현금매출 파일 첨부`에 선택한 홈택스 현금영수증 파일의 월별 금액을
사용합니다. 관별·항목별 배분비율은 SLS의 동일 월·매출구분 구성비입니다.

홈택스 기준 조회에서도 현금·판매대행·신용카드·합산액 Excel 4개를 함께 저장할 수
있으며, 첨부자료 기준 파일과 구별되도록 파일명에 `홈택스기준`이 표시됩니다.

지원하는 예시 형식:

- KSNET KSTA PG 부가세 PDF의 월별 거래금액
- KSNET 마이장부 Excel의 년월·승인금액
- NHN KCP 신용카드·가상계좌·계좌이체 부가세 신고 명세서
- 홈택스 현금영수증 매출 Excel의 승인·취소가 반영된 총금액
- 홈택스 신용카드·제로(온누리)페이 및 판매(결제)대행 매출자료 자동 분류

NHN KCP 파일 중 파일명에 `계좌이체` 또는 `가상계좌`가 포함된 자료는 첨부 위치와
관계없이 항상 판매(결제)대행매출로 분류됩니다.

KSNET 마이장부 신용카드매출은 월별 `신용합계`만 사용합니다. 현금영수증과
`현금합계`·`월별합계`는 신용카드매출에서 제외하며, 카드사 상세 행도 신용합계와
중복되므로 다시 더하지 않습니다.

홈택스 파일은 **홈택스 파일 첨부 · 자동분류**에서 여러 개를 선택합니다. 동일 분기의
월별 상세자료와 분기 통합자료를 함께 첨부하면 분기 통합자료는 검증용으로 인식하고
중복 합산하지 않습니다.

## 프로젝트 저장·불러오기

메인 화면의 **프로젝트 저장**은 SLS, 구분별 참고자료, 홈택스 자료의 첨부 경로를
`.rkproject` 파일에 저장합니다. **프로젝트 불러오기**를 누르면 모든 첨부 파일과
집계 결과를 다시 불러옵니다. 원본 파일을 이동하거나 삭제하면 프로젝트에서 찾을 수
없으므로 원본 경로를 유지해야 합니다.

## 분류 기준

- 현금/계좌 + 가상계좌 → 현금매출
- 창구카드 → 신용카드매출
- 이카드 → 판매(결제)대행매출
- 각 결제수단의 환불이 반영된 `순수납` 금액 사용
- 국풍온 수강료, H&C 평생교육원 노원 수강료 → 런케이에듀 수강료
- 모든 관의 교재비 → 교재매출
- 런케이에듀 CP를 제외한 모든 관의 컨텐츠/콘텐츠 → 가맹점유저
- 런케이에듀 CP 수강료 → 가맹점유저
- 런케이에듀 CP 교재비 → 교재매출
- 런케이에듀 CP 컨텐츠/콘텐츠/기타 → 가맹점매출
- 그 밖의 수강료와 항목은 국풍2000 매출로 보아 제외
